## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ออกแบบมาเพื่อพาคุณจากนักพัฒนามือใหม่ไปสู่ระดับมืออาชีพด้าน Clojure อย่างเป็นระบบ ครอบคลุมตั้งแต่แนวคิดพื้นฐานของ Functional Programming ไปจนถึงการสร้างระบบขนาดใหญ่ระดับ Production

### ทำไมต้อง Clojure?
- **Functional First**: เขียนโค้ดที่ถูกต้อง ทดสอบง่าย แก้ bugs น้อยลง
- **JVM Power**: ใช้ทุก library ของ Java ได้ทันที
- **Immutable Data**: ไม่มี state mutation bugs
- **REPL-Driven Development**: พัฒนาเร็วกว่า feedback loop สั้น
- **Production-Proven**: ใช้งานจริงที่ Nubank, Stripe, Walmart, NASA
